\# SmartCart – Customer Segmentation System



\## Project Overview

SmartCart is an Unsupervised Machine Learning project focused on customer segmentation. It analyzes 2,240 customer records with 22 attributes to understand purchasing behavior, spending patterns, and customer engagement.



\## Project Objectives

\- Analyze customer purchasing behavior.

\- Identify customer segments.

\- Understand spending patterns and engagement.

\- Generate insights for personalized marketing and customer retention.



\## Technologies Used

\- Python

\- Pandas

\- NumPy

\- Scikit-learn

\- Matplotlib

\- Seaborn

\- Jupyter Notebook



\## Machine Learning Techniques

\- K-Means Clustering

\- Agglomerative (Hierarchical) Clustering

\- Principal Component Analysis (PCA)



\## Project Workflow

1\. Data Loading

2\. Data Cleaning and Preprocessing

3\. Feature Engineering

4\. Exploratory Data Analysis (EDA)

5\. Feature Standardization using StandardScaler

6\. Dimensionality Reduction using PCA

7\. Customer Segmentation using K-Means and Agglomerative Clustering

8\. Cluster Visualization and Analysis
